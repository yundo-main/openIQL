# @openiql/core

Lexer, parser, schema validation, resolver and AST types for OpenIQL — an
open, dependency-free Issue Query Language.

```ts
import { analyze, analyzeRequest, createSchema } from '@openiql/core';
```

Pair with a backend adapter: `@openiql/adapter-postgres`,
`@openiql/adapter-sql` (SQLite/MySQL/ANSI), or `@openiql/adapter-opensearch`.

Docs & manual: https://github.com/yundo-main/openIQL · Apache-2.0
