백엔드 무관

같은 쿼리가 PostgreSQL·SQLite·MySQL·OpenSearch로 변환됩니다. 어댑터만 바꾸면 됩니다.

하나의 쿼리, 세 개의 백엔드

project = PROJ AND status != Done ORDER BY created DESC
SELECT issues.* FROM issues
WHERE (issues.project_key = $1
  AND issues.status IS DISTINCT FROM $2)
ORDER BY issues.created_at DESC
-- params: ['PROJ', 'Done']
SELECT issues.* FROM issues
WHERE (issues.project_key = ?
  AND (issues.status <> ? OR issues.status IS NULL))
ORDER BY issues.created_at DESC
-- params: ['PROJ', 'Done']
{ "query": { "bool": {
    "must": [{ "term": { "project_key.keyword": "PROJ" } }],
    "must_not": [{ "term": { "status.keyword": "Done" } }]
  }},
  "sort": [{ "created_at": { "order": "desc" } }] }

연동 구조

라이브러리로 포함 — 별도 서버 없이 API 핸들러 안에서 함수 호출로 동작합니다. ?q= 텍스트와 ?filter= JSON AST를 하나의 엔드포인트(analyzeRequest)로 받고, 권한 스코프는 paramOffset으로 WHERE에 병합합니다.

어댑터

패키지출력특징
@openiql/adapter-postgres{ sql, params } · $nIS DISTINCT FROM · ILIKE · EXISTS 이력 서브쿼리
@openiql/adapter-sql{ sql, params } · ?sqlite / mysql / ansi 방언, JSON 커스텀 필드
@openiql/adapter-opensearch{ body }.keyword 주소지정 · nested changelog · wildcard

검증됨

  • 136개 테스트 — PostgreSQL 16 · MariaDB 11 · OpenSearch 2 · node:sqlite 실DB 통합 스위트 포함 (CI 실행)
  • 보안 기본값 — 스키마 화이트리스트, 값 바인딩, 쿼리 2KB·깊이·목록 한도
  • 클린룸 + DCO — 모든 기여에 Signed-off-by, 법무 검토 기록 공개
  • Apache-2.0, @openiql/core는 런타임 무의존성 — 브라우저 번들 포함 가능
